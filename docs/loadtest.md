- p50·p95·p99는 Locust Aggregated 행 값이다. Locust는 1초가 넘는 응답 시간을 100ms 단위로 반올림해 기록한다. 평균은 1.28 / 1.38 / 1.45초, 최대는 1.34 / 1.48 / 1.61초였다.
- RPS는 휴지 시간(0.5~1.5초)을 포함한 값이라, 동시 사용자 수보다 실행 중인 요청 수(최대 1 / 7 / 23)가 적다.

## 해석

1. 동시 사용자 1 → 32명에서 RPS는 0.43 → 12.96(30배), 생성 토큰/초는 53 → 1,620(31배)으로 거의 비례해 늘었고, p95 지연은 1.3 → 1.5초(+15%)만 늘었다. vLLM 연속 배칭이 동시 요청을 같은 GPU 계산으로 묶어 처리하기 때문이다.
2. 대기열(num_requests_waiting)은 세 회차 모두 0이고 KV 캐시 최대 사용률은 3.0%다. 이 범위에서는 KV 캐시와 대기열이 병목이 아니다.
3. GPU 사용률은 8명부터 평균 99~100%다. 32명보다 더 늘리면 토큰당 디코드 시간이 늘어 지연이 먼저 커질 가능성이 높다(계산 병목 후보). 32명 초과 부하는 이번 범위 밖이라 측정하지 않았다.
